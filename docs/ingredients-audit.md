## 4. Measurement inconsistencies — summary

| Ingredient | Units used across recipes |
|-----------|--------------------------|
| Chicken stock | cups, ml, litres, grams, "container" |
| Garlic | cloves, tsp, tbsp, grams, powder |
| Onion | count (no weight), size descriptors (small/medium/large), grams |
| Cream | cups, ml, tbsp |
| Coconut milk | grams, ml, cans (size unspecified), tbsp |
| Canned tomatoes | grams, oz, "1 can" (size varies 280g–405g) |
| Cheese | cups, grams, mixed (e.g. "¾ cup (75g)") |
| Soy sauce | tsp, tbsp, grams |
| Rice | cups (cooked vs uncooked), grams |
| Oil | tbsp, spray (no quantity) |

---

## Key priorities for standardisation

1. **Meat quantities** — round to nearest 500g where possible; remove imperial (lb/oz) where a metric equivalent is given
2. **Stock** — standardise to ml throughout
3. **Garlic** — standardise to cloves throughout (remove purée/tsp variants where possible)
4. **Coconut milk** — standardise to "1 can (400ml)" as the base unit
5. **Canned tomatoes** — standardise to grams (400g or 800g)
6. **Mingle branded seasonings** — consider substituting with generic equivalents
7. **Non-local ingredients** — flag for substitution where a common alternative exists (e.g. arrowroot → cornflour, tamari → soy sauce, hatch chiles → regular green chiles)
